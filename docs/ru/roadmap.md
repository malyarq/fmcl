# Продуктовый ограничитель

Этот короткий документ заменяет прежний пофазовый инженерный роадмап. Выпущенная работа описывается в [истории изменений](../../CHANGELOG.md), технические контракты — в соседней документации, старые решения остаются в истории Git.

## Текущее условие остановки

После следующего релиза не начинать новый архитектурный этап, пока Burrow не попробуют хотя бы **20 внешних пользователей**, а мейнтейнер не разберёт их добровольную аналитику и отзывы. Наблюдаемые ошибки установки, запуска, обновления, восстановления и Burrow Link важнее предположительных новых подсистем.

## Чего ещё не хватает для уверенной публичной альфы

- Проверить чистую установку, первый запуск, запуск Minecraft, обновление и удаление на Windows, macOS и Linux.
- Зарегистрировать и подключить Microsoft Auth до заявления о поддержке официальных аккаунтов.
- Подписать пакеты Windows и подписать/нотарифицировать пакеты macOS, когда появятся данные издателя.
- Проверить в облачном проекте PostHog, что сбор IP выключен, профили пользователей не создаются, а срок хранения соответствует документации.
- Включать каталог CurseForge только после решения вопросов ключей API, атрибуции, правил распространения, тестов и обработки ошибок.

Это продуктовые и дистрибуционные ограничения, а не разрешение начать новый внутренний рефакторинг. Следующий инженерный приоритет должен появиться из внешних данных либо конкретного дефекта безопасности или надёжности.
