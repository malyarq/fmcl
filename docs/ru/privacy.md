# Приватность и аналитика

FriendLauncher работает без аналитики. Анонимная продуктовая аналитика **по умолчанию выключена** и запускается только после того, как пользователь включит её в разделе **Настройки → Лаунчер → Приватность и обратная связь**. После выключения новые события не отправляются, а локальный случайный идентификатор аналитики удаляется.

## Необязательная аналитика

Официальные сборки используют PostHog EU Cloud и только небольшой проверенный список событий:

| Событие | Свойства |
| --- | --- |
| Открытие приложения | Версия FMCL, семейство операционной системы, язык интерфейса и режим «Классика/Модпаки» |
| Начало запуска Minecraft | Версия FMCL, семейство операционной системы и семейство модлоадера |
| Успешный или неуспешный запуск Minecraft | Версия FMCL, семейство операционной системы, семейство модлоадера и ограниченный этап ошибки |
| Показ первого запуска или выбранное действие | Версия FMCL, семейство операционной системы и ограниченное действие: игра, модпаки, FriendTunnel, настройки или добровольный обзор |
| Завершение операции с модпаком | Версия FMCL, семейство операционной системы, ограниченный тип операции и результат; без идентификаторов проекта, сборки, файла или провайдера |
| Состояние FriendTunnel | Версия FMCL, семейство операционной системы, роль хоста/участника и ограниченный этап запуска, подключения друга или ошибки |
| Экспорт или импорт настроек | Только версия FMCL и семейство операционной системы |
| Открытие обратной связи на GitHub | Версия FMCL, семейство операционной системы и фиксированный источник `launcher_settings` |

FMCL создаёт случайный идентификатор установки только после согласия пользователя. Он не вычисляется из оборудования, аккаунта, ника или пути к файлам. События отправляются в PostHog как анонимные/personless; FMCL не вызывает PostHog identify API. Каждое событие содержит `$geoip_disable: true`, чтобы PostHog не выполнял GeoIP-обогащение.

FMCL **не отправляет** данные аккаунтов, ники, access tokens, коды комнат, адреса серверов, пути Minecraft, имена файлов, логи, содержимое форм, тексты ошибок, скриншоты, запись сессии, рекламные идентификаторы или точную геолокацию. Интеграция не загружает браузерный SDK PostHog и не использует autocapture, cookies, heatmaps или session replay.

При сетевой отправке процессор аналитики технически получает метаданные соединения. Проект FMCL в PostHog должен находиться в EU-регионе, иметь выключенный сбор IP и хранить аналитику не дольше 12 месяцев. Код репозитория не может сам проверить настройку облачного проекта, поэтому это отдельный пункт проверки владельца релиза.

## Отчёты о проблемах

Кнопка **Сообщить о проблеме на GitHub** локально готовит предпросмотр только с версией FMCL, семейством ОС, языком интерфейса и состоянием аналитики. Автоматической отправки нет. Пользователь проверяет и редактирует черновик на GitHub, а затем сам отправляет его по правилам GitHub.

Не добавляйте в публичный issue учётные данные, идентификаторы аккаунтов, коды комнат, приватные адреса серверов, личные пути к файлам или сведения об уязвимости. Об уязвимостях сообщайте через [приватный канал](https://github.com/malyarq/fmcl/security/advisories/new).

## Управление и вопросы

- Оставьте аналитику выключенной, чтобы не отправлять продуктовые события.
- Выключите её позже, чтобы прекратить сбор и удалить локальный случайный идентификатор.
- Если вы сами отправили информацию на GitHub, удалите соответствующий issue или комментарий средствами GitHub.
- Задайте вопрос о приватности через [GitHub Issue](https://github.com/malyarq/fmcl/issues/new), не добавляя туда личные данные.

Документ описывает текущую реализацию. Существенное изменение состава данных требует обновить код, тесты, переводы и это уведомление до релиза.
