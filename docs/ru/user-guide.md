# Руководство пользователя FriendLauncher

Документ относится к текущей стабильной версии. Подтверждённые ограничения перечислены в [известных проблемах](known-issues.md).

## Установка

1. Откройте [последний релиз на GitHub](https://github.com/malyarq/fmcl/releases/latest).
2. Скачайте файл для своей операционной системы и `SHA256SUMS.txt`.
3. Сравните SHA-256 файла с соответствующей строкой в `SHA256SUMS.txt`.
4. Установите или запустите приложение.

| Платформа | Файл | Установка |
| --- | --- | --- |
| Windows | `FriendLauncher-Windows-<version>-Setup.exe` | Запустите установщик. |
| macOS | `FriendLauncher-Mac-<version>-Installer.dmg` | Откройте образ и перенесите FriendLauncher в Applications. |
| Linux | `FriendLauncher-Linux-<version>.AppImage` | Разрешите выполнение файла и запустите его. |

Сборки для Windows и macOS пока не подписаны. Предупреждение о неизвестном разработчике ожидаемо, но само по себе ничего не говорит о безопасности файла. Проверьте, что файл скачан с `github.com/malyarq/fmcl`, и сравните контрольную сумму.

### Проверка скачанного файла

macOS или Linux:

```bash
shasum -a 256 FriendLauncher-<platform>-<version>.<extension>
```

Windows PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 .\FriendLauncher-Windows-<version>-Setup.exe
```

Полученное значение должно совпасть со строкой в `SHA256SUMS.txt`. Если значения отличаются, файл нельзя использовать.

## Первый запуск

1. Просмотрите приветственный экран, запустите пошаговую подсказку или пропустите её.
2. Откройте **Аккаунты** и создайте офлайн-профиль либо добавьте поддерживаемый сторонний аккаунт.
3. В **Настройках** выберите язык и оформление; там же при необходимости задаются папка игры, зеркало загрузок, объём памяти и путь к Java.
4. В разделе **Классика** выберите версию Minecraft и модлоадер, затем нажмите **Играть**.

FMCL подбирает Java 8, 17 или 21 по версии Minecraft. Сначала используется указанный или найденный локальный runtime; если подходящего нет, лаунчер может скачать его самостоятельно.

## Модпаки и контент

- Создайте локальный инстанс на экране модпаков.
- Установите сборку из Modrinth либо импортируйте локальный архив CurseForge/Modrinth.
- Внутри инстанса можно управлять модами, ресурспаками, шейдерами, мирами, датапаками и скриншотами.
- Перед крупным обновлением или удалением экспортируйте либо сохраните резервную копию важной сборки.

Просмотр каталога CurseForge в официальных сборках отключён. Импорт и экспорт локальных архивов, а также коды шаринга остаются доступны.

## Мультиплеер

FriendTunnel соединяет мир Minecraft, открытый для локальной сети, по коду комнаты:

1. Хост открывает мир для LAN и копирует порт, показанный в чате Minecraft.
2. Хост запускает FriendTunnel с этим портом и передаёт код комнаты второму игроку.
3. Второй игрок подключается по коду комнаты.

LAN discovery и UPnP зависят от локальной сети и роутера. Это дополнительные режимы; для обычного FriendTunnel они не нужны.

## Обновления

Лаунчер может автоматически проверять обновления приложения и модпаков, но скачивание обновления приложения начинается только после подтверждения. Стабильные версии можно установить из уведомления в приложении или со страницы Releases.

## Данные и резервные копии

Папка игровых данных задаётся в настройках. Конфигурация приложения хранится в каталоге Electron `.fmcl`, обычно:

- Windows: `%APPDATA%\.fmcl`
- macOS: `~/Library/Application Support/.fmcl`
- Linux: `~/.config/.fmcl`

Перед переносом на другой компьютер или ручным восстановлением сохраните и папку игровых данных, и `.fmcl`. Не удаляйте эти каталоги как универсальный способ починки.

## Приватность и обратная связь

Анонимная продуктовая аналитика по умолчанию выключена. Карточка **Приватность и обратная связь** в настройках лаунчера показывает точный состав данных и позволяет включить или выключить отправку. Кнопка отчёта на GitHub сначала показывает безопасный черновик и ничего не отправляет автоматически. Полный список событий и управление данными описаны в документе [Приватность и аналитика](privacy.md).
