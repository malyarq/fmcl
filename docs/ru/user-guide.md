# Руководство пользователя Burrow

Документ относится к текущей стабильной версии. Подтверждённые ограничения перечислены в [известных проблемах](known-issues.md).

## Установка

1. Откройте [последний релиз на GitHub](https://github.com/malyarq/burrow/releases/latest).
2. Скачайте файл для своей операционной системы и `SHA256SUMS.txt`.
3. Сравните SHA-256 файла с соответствующей строкой в `SHA256SUMS.txt`.
4. Установите или запустите приложение.

| Платформа | Файл | Установка |
| --- | --- | --- |
| Windows | `Burrow-Windows-<version>-Setup.exe` | Запустите установщик. |
| macOS | `Burrow-Mac-<version>-Installer.dmg` | Откройте образ и перенесите Burrow в Applications. |
| Linux | `Burrow-Linux-<version>.AppImage` | Разрешите выполнение файла и запустите его. |

Windows-пакеты и macOS DMG пока не подписаны издателем. Внутри локальной macOS-сборки может быть ad-hoc подпись, но она только позволяет запускать приложение после настройки fuses и не подтверждает издателя. Предупреждение о неизвестном разработчике ожидаемо, но само по себе ничего не говорит о безопасности файла. Проверьте, что файл скачан с `github.com/malyarq/burrow`, и сравните контрольную сумму.

### Проверка скачанного файла

macOS или Linux:

```bash
shasum -a 256 Burrow-<platform>-<version>.<extension>
```

Windows PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 .\Burrow-Windows-<version>-Setup.exe
```

Полученное значение должно совпасть со строкой в `SHA256SUMS.txt`. Если значения отличаются, файл нельзя использовать.

## Первый запуск

1. Выберите русский или английский прямо на приветственном экране.
2. Выберите нужный результат: **Играть в Minecraft**, **Играть с другом** или **Запустить модпак**. Короткий обзор запускается только по желанию.
3. Для обычной игры укажите ник, версию Minecraft и при необходимости модлоадер в разделе **Классика**, затем нажмите **Играть**.
4. Открывайте **Настройки**, только когда нужно изменить оформление, папки, зеркала, память, Java, аккаунты, приватность или резервную копию.

Офлайн-игра работает сразу. Вход Microsoft пока недоступен; поддерживаемый сторонний Yggdrasil-аккаунт можно добавить в настройках.

Burrow подбирает Java 8, 17 или 21 по версии Minecraft. Сначала используется указанный или найденный локальный runtime; если подходящего нет, лаунчер может скачать его самостоятельно.

## Модпаки и контент

- Создайте локальный инстанс на экране модпаков.
- Установите сборку из Modrinth либо импортируйте локальный архив CurseForge/Modrinth.
- Внутри инстанса можно управлять модами, ресурспаками, шейдерами, мирами, датапаками и скриншотами.
- Перед крупным обновлением или удалением экспортируйте либо сохраните резервную копию важной сборки.

Просмотр каталога CurseForge в официальных сборках отключён. Импорт и экспорт локальных архивов, а также коды шаринга остаются доступны.

## Мультиплеер

Burrow Link соединяет мир Minecraft, открытый для локальной сети, по приглашению:

1. Хост открывает мир для LAN и копирует порт, показанный в чате Minecraft.
2. Хост запускает Burrow Link с этим портом и копирует приглашение вида `BURROW-…`.
3. Второй игрок вставляет приглашение в Burrow Link.
4. После готовности соединения второй игрок открывает в Minecraft **Сетевая игра → Прямое подключение** и вводит адрес `localhost:<порт>`, который показал Burrow.

Приглашение содержит закрытый секрет соединения. Передавайте его только нужному человеку и останавливайте сессию после игры.

LAN discovery и UPnP зависят от локальной сети и роутера. Это дополнительные режимы; для обычного Burrow Link они не нужны.

## Обновления

Лаунчер может автоматически проверять обновления приложения и модпаков, но скачивание обновления приложения начинается только после подтверждения. Стабильные версии можно установить из уведомления в приложении или со страницы Releases.

## Данные и резервные копии

Папка игровых данных задаётся в настройках. Новая установка хранит конфигурацию приложения в каталоге Electron `Burrow`, обычно:

- Windows: `%APPDATA%\Burrow`
- macOS: `~/Library/Application Support/Burrow`
- Linux: `~/.config/Burrow`

В разделе **Настройки → Хранилище → Экспортировать настройки** можно создать переносимую резервную копию JSON. В неё намеренно не входят данные аккаунтов, согласие и идентификатор аналитики, коды Burrow Link, локальные пути, игровые файлы, миры и модпаки. Импорт заменяет только поддерживаемые настройки и перезапускает интерфейс.

Важные модпаки экспортируйте отдельно. Для полной ручной копии сохраните папку игровых данных и каталог приложения `Burrow`. Не удаляйте эти каталоги как универсальный способ починки.

## Приватность и обратная связь

Анонимная продуктовая аналитика по умолчанию выключена. Карточка **Приватность и обратная связь** в настройках лаунчера показывает точный состав данных и позволяет включить или выключить отправку. Кнопка отчёта на GitHub сначала показывает безопасный черновик и ничего не отправляет автоматически. Полный список событий и управление данными описаны в документе [Приватность и аналитика](privacy.md).

## Помощь

Сначала откройте [решение проблем](troubleshooting.md). Если это не помогло, нажмите **Настройки → Лаунчер → Сообщить о проблеме на GitHub** или создайте [GitHub Issue](https://github.com/malyarq/burrow/issues/new). Добавьте шаги воспроизведения, а экспорт консоли прикладывайте только после удаления секретов и личных путей.

Об уязвимостях сообщайте приватно по правилам из [SECURITY.md](../../SECURITY.md).
