# Решение проблем

Здесь собраны типовые пользовательские ошибки стабильной версии. Не удаляйте папку игровых данных или каталог `Burrow`, пока не сделали резервную копию.

## Операционная система блокирует установщик

Windows-пакеты и macOS DMG пока не подписаны издателем. Ad-hoc подпись локального macOS-приложения не подтверждает личность издателя. Убедитесь, что файл скачан с [официальной страницы релизов](https://github.com/malyarq/burrow/releases/latest), и проверьте SHA-256 по инструкции из [руководства](user-guide.md). Если сумма не совпадает, удалите файл.

Подпись издателя и notarization сейчас не настроены, поэтому Burrow не может самостоятельно убрать предупреждение операционной системы.

## Minecraft не запускается

1. Откройте консоль лаунчера и сохраните последнюю ошибку вместе с несколькими строками перед ней.
2. Проверьте совместимость выбранных версий Minecraft и модлоадера.
3. Временно уберите вручную заданный путь к Java, чтобы Burrow нашёл или скачал нужную версию.
4. Убедитесь, что папка игровых данных существует и на диске достаточно места.
5. Повторите запуск, не меняя одновременно несколько настроек.

Версии Minecraft до 1.17 обычно требуют Java 8, начиная с 1.17 — Java 17, а начиная с 1.20.5 — Java 21. Burrow применяет это правило автоматически, но принудительно выбранная несовместимая Java всё равно может сломать запуск.

## Не устанавливается Java

- Проверьте доступ к метаданным и файлам runtime Mojang.
- Укажите в настройках приложения или инстанса заведомо рабочий Java home либо исполняемый файл.
- Не выбирайте случайную папку, в которой вместе лежат несвязанные программы.
- В отчёте об ошибке укажите требуемую и найденную версии Java.

## Не работают загрузки или каталог

- Повторите запрос один раз, чтобы исключить временный сбой провайдера.
- Верните автоматический выбор зеркала загрузок.
- Проверьте свободное место и права на запись.
- Прокси, DNS-фильтр, антивирус или корпоративная сеть могут блокировать Mojang, Modrinth, GitHub и хосты Java-артефактов.
- Каталог CurseForge в официальных сборках намеренно недоступен; используйте импорт архива или код шаринга.

## Лаунчер отклоняет архив модпака

Burrow блокирует небезопасные и повреждённые архивы: выход за целевую папку, ссылки, повторяющиеся пути, зашифрованные записи и превышение защитных лимитов. Используйте исходный экспорт CurseForge или Modrinth и не перепаковывайте его с абсолютными путями.

Если локальный инстанс создался, а обновление метаданных завершилось ошибкой, сначала заново откройте список модпаков. Инстанс уже может существовать.

## Не устанавливается мод или другой контент

- Убедитесь, что у файла есть версия для выбранных Minecraft и модлоадера.
- Проверьте, разрешает ли провайдер прямое скачивание файла.
- Повторите попытку с того же экрана; там, где предусмотрено восстановление, неудачные позиции остаются выбранными.
- Для ресурспаков и шейдеров используйте локальный `.zip`, если каталог провайдера недоступен.

## Burrow Link не соединяется

- Хост должен открыть мир для LAN и ввести порт, показанный Minecraft в чате, а не предполагаемый стандартный порт.
- Передавайте код комнаты только после запуска сессии хоста.
- Если мир был открыт заново, Minecraft мог выбрать другой LAN-порт — перезапустите соединение с обеих сторон.
- LAN discovery и UPnP требуют поддержки сети и роутера. Если они не работают, используйте обычный режим Burrow Link.

## Зависло обновление приложения

Скачивание начинается только после подтверждения. Если обновление внутри приложения не установилось, закройте Burrow и установите ту же стабильную версию со страницы Releases. Не заменяйте вручную файлы внутри запущенного приложения.

## Как составить полезный баг-репорт

Приложите:

- версию Burrow и операционную систему;
- версию Minecraft, модлоадер и тип инстанса;
- точные шаги воспроизведения;
- ожидаемый и фактический результат;
- экспорт консоли лаунчера;
- результат проверки на новом локальном инстансе.

Перед публикацией удалите из логов access/client tokens, идентификаторы аккаунтов, коды комнат и личные пути файловой системы. Обычные ошибки отправляйте в [GitHub Issues](https://github.com/malyarq/burrow/issues/new), уязвимости — только через [приватный канал](../../SECURITY.md).
